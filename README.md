# All Yono Games — New Website Draft

This is a separate draft based on the uploaded Yono-Games source ZIP.

## Design
- Simple navy blue, cream, and gold colour palette
- Existing HTML pages and local image assets retained
- Old custom-domain CNAME and Google Search Console verification removed
- Canonical URLs intentionally omitted until the new domain is purchased

## Before publishing
1. Confirm all individual game pages have unique, accurate descriptions and page titles.
2. Test all game links and download links; replace broken or unverified links.
3. Add the purchased domain to canonical tags, Open Graph URLs, sitemap.xml, and robots.txt.
4. Add a new Search Console verification token for the new property.
5. Check mobile layout, image loading, and all navigation links.

This is a development draft and has not been published or verified live.
